# BiggerCritTextSize

## Summary
Increase display text size for crit number.

## Steps to Build the Mod
1. Install .NET SDK.
2. Update `DuckovPath` in `BiggerCritTextSize.csproj`.
3. Run `dotnet build`.
4. After build, you should see a bin folder. Find `BiggerCritTextSize.dll` inside the bin folder.
5. Follow https://github.com/xvrsl/duckov_modding and create a mod folder inside the game folder with the following files:
    - BiggerCritTextSize.dll (From step 4)
    - 0Harmony.dll (From https://github.com/pardeike/Harmony)
    - info.ini
    - preview.png
